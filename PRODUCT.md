# Product

## Register

product

## Users

React and Next.js developers using JavaScript or TypeScript. They want to inspect
motion, install a small library, and adapt components without rewriting the engine.

## Product Purpose

MorphUI is an MIT-licensed library of three morphing primitives. Its documentation
lets developers experience each component, read the matching API and copy a working
example. Motion quality and ease of customization are the main product benefits.

## Brand Personality

Calm, precise, tactile. Product copy is English. Components are the visual focus.

## Anti-references

No decorative monospace, uppercase tracked section labels, ornamental section
numbers, neon accents, testimonial filler or invented adoption claims. beui.dev
is an information-architecture reference, not a visual template.

## Design Principles

Preserve continuity between triggers and content. Let developers try before they
install. Use one semantic design system in light and dark. Keep the site in Ink
while allowing scoped theme previews. Document the shipped API and release status.

## Accessibility & Inclusion

Keyboard navigation, visible focus, labelled controls, native dialog semantics,
reduced motion, readable contrast and responsive layouts are baseline requirements.
